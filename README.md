# Executive Sales & Profit Overview - Power BI Dashboard

## 📊 Despre Proiect
Acest proiect prezintă un dashboard interactiv realizat în Power BI pentru analiza performanței de vânzări ale unei companii de retail ($85M+ venituri, 113K tranzacții).

## 🚀 Indicatori Cheie & Funcționalități
- **KPIs:** Total Revenue, Total Profit, Total Orders, Profit Margin %.
- **Analiză Demografică & Categorii:** Performanța pe grupe de vârstă, gen și categorii de produse (Bikes, Accessories, Clothing).
- **Simulare What-If:** Parametru interactiv pentru a simula creșterea profitului în cazul scumpirii prețurilor cu până la 20%.

## 🛠️ Tehnologii Folosite
- **Power BI Desktop**
- **DAX** (Măsuri calculate & Parametri What-If)
- **Power Query** (Curățare și transformare date)
